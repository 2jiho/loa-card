# LoaCard

로스트아크 카드 성장 화면을 공유하면 이름·각성·추가 장수를 읽어 목록으로 만드는 정적 웹앱입니다. 화면 판독과 계산은 브라우저 안에서 처리하며 외부 OCR API로 화면을 보내지 않습니다.

- **내 카드**: 화면 공유 스캔, 등록/미등록 목록, 이름 검색, CSV 저장·불러오기.
- **떠돌이 상인**: 지역별 카드 재료 확보 현황과 한국 시간 기준 등장 시간표. 게임 알림은 사용자가 직접 설정합니다.
- **도감작**: 수집 효과, 경험치 효율에 따른 단계별 성장 순서, 성장 완료·실행 취소.
- **레이드 카드**: 일반적인 카드 세트의 현재/성장 가능 각성과 속성별 비교.

## 로컬 실행

Node.js 22와 npm이 필요합니다. 저장소 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다. 최초 실행은 고정 버전 OCR 모델을 공개 배포처에서 내려받고 SHA-256을 확인합니다. 백엔드, API 키, 게임 설치 또는 개인 영상이 빌드에 필요하지 않습니다.

Chrome 또는 Edge에서 **화면 공유 시작**을 누르고 준비가 끝나면 게임의 카드 **성장** 탭을 스크롤합니다. 이름·각성·장수가 가려지지 않게 커서를 옮겨 주세요. 필요한 이름과 보관함 수량이 확인되면 공유를 종료하고 남은 판독을 마무리합니다. 공유 종료와 전체 필드 확인은 별개입니다.

같은 보관함을 다시 스캔하면 최신 관측으로 갱신합니다. 다른 계정은 **목록 초기화** 후 시작합니다. 완료 목록은 같은 주소의 브라우저 저장소에 저장되어 새 탭에서도 복원되며 별도 보관에는 CSV를 사용합니다.

CSV는 `이름,각수,카드수` 세 열입니다. 행이 있으면 등록 카드이며 카드수는 각성에 쓰지 않은 추가 장수입니다. 잘못된 값은 파일 전체를 거부합니다. CSV에는 경험치·캡처 사진·실행 취소 이력이 없으며 불러오기는 기존 목록을 교체합니다.

## 개발과 검증

```sh
npm run lint
npm test
npm run build
npm run preview
```

- [개발 지침](AGENTS.md): 변경 시 지켜야 할 규칙.
- [문서 안내](docs/README.md): 구조, 기능, 데이터, 테스트, 배포.
- 개발 입력 화면: dev 서버의 `/dev/scanner.html`. 로컬 영상·이미지를 선택해 실제 스캐너를 실행합니다. 일반 배포에는 포함하지 않습니다.
- `fixtures/local/`, `work/`: 선택적인 개인 검사 자료이며 Git·배포에서 제외합니다. 커밋된 테스트 fixture와 마스터만으로 일반 테스트·빌드를 실행합니다.

GitHub Pages 배포는 수동 워크플로를 제공합니다. 저장소 하위 경로·배포 확인 절차는 [배포 안내](docs/deployment.md)을 따릅니다.
