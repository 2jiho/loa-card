# LoaCard

로스트아크의 카드 성장 화면을 공유하면 카드마다 이름·각성·추가 장수를 읽어 목록으로 만들어 주는 웹앱입니다. 서버 없이 브라우저 안에서만 동작하며, 공유한 화면을 다른 서버로 보내지 않습니다.

- **내 카드**: 화면 공유 스캔, 등록/미등록 목록, 이름 검색, CSV 저장·불러오기.
- **떠돌이 상인**: 지역별로 더 모아야 할 카드와 한국 시간 기준 등장 시간표. 게임 안의 알림은 직접 설정해야 합니다.
- **도감작**: 수집 효과를 고르면 경험치 대비 효과가 큰 순서로 성장 순서를 계산합니다. 게임에서 성장시킨 뒤 '성장 완료'로 목록에 반영하고, 되돌릴 수도 있습니다.
- **레이드 카드**: 자주 쓰는 카드 세트마다 지금 각성과, 가진 카드로 올릴 수 있는 각성을 속성별로 비교합니다.

## 로컬 실행

Node.js 22와 npm이 필요합니다. 저장소 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 나온 로컬 주소를 엽니다. 처음 실행할 때는 글자 인식(OCR) 모델을 공개 배포처에서 내려받고 SHA-256 해시를 확인하므로 인터넷 연결이 필요합니다. 빌드에 백엔드, API 키, 게임 설치 파일, 개인 영상은 필요하지 않습니다.

페이지를 열면 스캔 준비를 바로 시작합니다. Chrome이나 Edge에서 준비가 끝나면 **화면 공유 시작**을 누르고, 로스트아크 창을 고른 뒤 카드 보관함의 **성장** 탭을 끝까지 넘깁니다.

게임 해상도는 1920×1080 이상을 권장합니다. 개발자의 보관함 한 개를 창 모드·전체 화면, 1920×1080·2560×1440·5120×2880으로 녹화해 다시 실행했을 때 모든 카드를 끝까지 읽었습니다. 다른 계정·환경에서도 항상 그렇다는 보장은 아닙니다. 1600×900처럼 더 작은 화면에서는 숫자가 작아 일부 각성·장수를 못 읽고 남을 수 있으며, 그때 스캐너가 안내를 보여 줍니다.

마우스를 **스크롤바 위에 두고 휠을 돌리거나 스크롤바를 끌어서** 천천히 넘겨 주세요. 카드 위에 마우스를 올리면 툴팁이 카드를 가립니다. 모든 카드의 이름·각성·장수를 읽고 보관함 수량과 맞으면 화면 공유가 자동으로 끝납니다. 공유 중에 못 읽은 카드가 있으면 진행 창의 목록 지도에 그 줄이 표시되니, 그 줄로 돌아가 잠깐 보여 주세요. 직접 공유를 끝내면 이미 받은 화면은 마저 읽습니다. 공유가 끝난 뒤 못 읽은 카드가 남았다면 다시 스캔해야 하며, 새 스캔은 목록을 처음부터 새로 읽습니다. 화면 위쪽 **사용법**에서 이 안내를 다시 볼 수 있습니다.

끝까지 마친 스캔 결과는 이 브라우저에 자동으로 저장되고, 같은 주소로 새 탭을 열어도 다시 보입니다. 끝까지 마치지 못한 스캔은 전에 저장한 목록을 바꾸지 않습니다. 다른 기기로 옮기거나 따로 보관하려면 CSV로 저장합니다. 다른 계정을 스캔할 때는 **목록 초기화** 후 시작합니다.

카드를 읽는 동안에도 떠돌이 상인·도감작·레이드 메뉴에 읽은 카드가 바로 반영됩니다. 아직 못 읽은 카드는 '미확인'으로 표시됩니다. '성장 완료' 버튼은 스캔이 끝난 뒤에 쓸 수 있습니다.

CSV는 `이름,각수,카드수` 세 열입니다. 파일에 있는 카드는 등록된 카드로 보고, 카드수는 각성에 쓰지 않은 추가 장수입니다. 이름·각성·장수를 못 읽은 카드가 있으면 CSV로 저장할 수 없으니 다시 스캔해 주세요. 불러올 때 값이 하나라도 잘못되면 파일 전체를 불러오지 않습니다. CSV에는 경험치·스캔한 화면·되돌리기 기록이 들어 있지 않고, 불러오면 지금 목록이 CSV의 목록으로 바뀝니다. 불러올 때 보유 카드 경험치를 적을 수 있으며, 비워 두면 '미확인', 0을 적으면 경험치 0으로 계산합니다.

## 개발과 검증

```sh
npm run lint
npm test
npm run build
npm run preview
```

- [개발 지침](AGENTS.md): 변경 시 지켜야 할 규칙.
- [문서 안내](docs/README.md): 구조, 기능, 데이터, 테스트, 배포.
- 개발 검증: dev 서버에서 화면을 공유하면 비공개 기록(`fixtures/local/recordings/`)이 남고, `/dev/recording.html`과 `scripts/run-recording-replay.mjs`로 같은 입력을 다시 실행합니다. 일반 배포에는 포함하지 않습니다.
- `fixtures/local/`, `work/`: 선택적인 개인 검사 자료이며 Git·배포에서 제외합니다. 커밋된 테스트 fixture와 마스터만으로 일반 테스트·빌드를 실행합니다.

`v0.1.0`부터 버전 태그로 관리합니다. 태그를 푸시하면 검증 → GitHub Pages 배포 → Release 생성이 자동 실행됩니다. [변경 내역](CHANGELOG.md)과 [버전·배포 안내](docs/deployment.md)를 참고하세요.
