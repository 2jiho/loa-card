# 출시 점검

검사한 커밋과 실행 환경을 결과에 함께 기록한다. 설치·빌드 성공과 데이터 배포 권한, 실제 게임 화면 판독은 별개의 확인 항목이다.

## 소스 공개 전

- README와 AGENTS의 명령만으로 빈 폴더에서 설치·검증할 수 있는지 확인한다.
- 추적 파일에 비밀키, 개인 경로, 전체 캡처, 원본 게임 DB·폰트·아카이브, 생성된 모델 캐시가 없는지 확인한다.
- 코드의 MIT와 게임 자료·외부 소프트웨어의 권리 표시를 구분한다.
- 클라이언트 썸네일, 인식 자료, 테스트 픽셀, DB 파생 마스터의 배포 범위를 결정한다. 미확인 사항은 [권리 검토](legal-review.md)에 남긴다.
- `npm run lint`, `npm test`, `npm run build`, `npm run audit:distribution`, `npm run verify:site -- --local`을 실행한다.
- `PAGES_BASE_PATH`를 실제 저장소 이름에 맞춰 빌드한다. `dist`의 개발 페이지·원본 자료 제외와 OCR·라이선스 자산 포함을 확인한다.

## Pages 배포 후

- 배포 URL과 빌드 커밋이 일치하는지 확인한다.
- 새 브라우저 상태에서 모델·Worker·WASM·라이선스 링크가 정상적으로 열리는지 확인한다.
- 화면 공유 시작·스크롤·자동 종료·잔여 판독 완료를 구분해서 확인한다.
- 새 탭 복원·여러 탭 저장 충돌·목록 초기화, CSV 입출력, 브라우저 저장, 재스캔, 도감 성장 완료·취소, 레이드·떠돌이 상인 화면을 확인한다.
- 밝은/어두운 모드, 좁은 화면, 키보드 이동을 확인한다.

위 항목이 끝나기 전에는 전체 카드 인식 보장이나 배포 검증 완료로 표현하지 않는다. 전체 화면이나 개인 목록을 공개 이슈에 첨부하도록 요구하지 않는다.

개별 출시 근거 감사는 `npm run audit:data -- --require-release-evidence`로 실행한다. 현재 미문서화 카드가 있어 이 엄격 검사는 실패한다. 메타데이터 무결성 검사 통과와 구분한다.
