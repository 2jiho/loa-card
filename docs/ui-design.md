# UI 컴포넌트와 테마

## 구성

MUI 9 + Emotion을 사용한다. Tailwind CSS는 도입하지 않는다.
- `src/ui/AppTheme.tsx`: MUI 테마, 시스템 색상 모드, 사용자 선택 저장, 모션 감소 설정.
- `src/ui/WorkspaceNavigation.tsx`: MUI Tabs/Tab, 메뉴 아이콘, 키보드 이동, 활성 패널 연결.
- `src/index.css`: 라이트/다크 공통 의미 색상 변수. 표면·글자·테두리·강조·등급·속성색.
- `src/App.css`: 앱 배치와 카드 그리드. 기능별 CSS도 같은 색상 변수를 사용한다.

데스크톱은 왼쪽 내비게이션과 오른쪽 작업 화면이다. 900px 이하에서는 메뉴가 상단으로 이동한다.
스캔·CSV 입력·목록 초기화는 내 카드 페이지에서만 표시한다. 캡처용 video 요소는 메뉴 전환 시에도 마운트한 채 숨긴다.
카드가 없거나 스캔·CSV 판독 중, 스캔 중지·오류 상태에서는 다른 메뉴를 비활성화한다. 판독을 마친 목록이나 정상 CSV·백업 목록이 있으면 활성화한다.
보유 경험치 등 요약은 다른 페이지에서도 표시한다. 스크린 캡처 미리보기는 작게 유지한다. 카드 목록의 페이지 크기는 40종이며 기존 반응형 열 수를 유지한다.

화면 공유/CSV 버튼, 검색·도감 필터 입력, 목록 필터·역할·취약 선택, 지역 아코디언,
비교 설정 팝오버에 MUI를 사용한다. 카드 이미지 그리드·도감 데이터 목록·성장 단계는 전용 컴포넌트를 유지한다.
컴포넌트 스타일은 MUI 테마와 해당 기능 CSS에서 관리하며 전역 일반 버튼 규칙은 MUI를 제외한다.

## 사용 안내

빈 목록에는 성장 탭 열기 → 게임 화면 공유 → 스크롤의 세 단계 안내를 표시한다. 백업을 복원하거나 스캔을 시작하면 접고, 헤더의 사용법 버튼은 모든 메뉴에서 유지한다. 강제로 여는 첫 방문 팝업이나 별도 완료 기록은 만들지 않는다.

MUI Dialog에 준비 대기, 공유 종료와 판독 완료의 차이, 누락·툴팁·검은 화면 대처, 결과 메뉴, CSV와 계정 전환을 안내한다. Esc·닫기와 초점 복귀를 지원한다. 스캔 도중 안내를 열어도 캡처 video와 인식 작업은 유지한다.

## 색상 모드

설정이 없으면 `prefers-color-scheme`을 따른다. 우측 상단 버튼으로 라이트/다크를 전환하면
`loacard-color-mode` 키에 선택을 저장한다. 저장소 접근 실패 시에도 현재 화면에서는 전환한다.
테마 설정은 카드 목록 백업과 별개다. 카드 초기화는 테마 설정에 영향을 주지 않는다.

색상은 `--surface`, `--text`, `--muted`, `--line`, `--accent` 같은 공통 변수를 사용한다.
카드 희귀도와 속성색도 모드별 값을 사용한다. 게임 캡처 이미지 자체는 바꾸지 않는다.

## 미등록 카드 원화

미등록 목록은 이름·등급과 검증된 클라이언트 원화 썸네일을 함께 표시한다. 같은 사이트의 `scanner/artwork/` 파일만 읽으며 외부 이미지 주소를 사용하지 않는다. 파일이 없거나 로드에 실패하면 같은 크기의 대체 아이콘을 표시한다. 이름 툴팁과 이미지 확대의 마우스·키보드 동작은 등록 목록과 같은 컴포넌트를 사용한다. 원화 유무는 보유/미보유 판정 근거가 아니다.

## 하단 고지

모든 메뉴에 비공식·무료·비상업 팬 도구, 제휴·보증 부재와 게임 자료의 권리 귀속을 표시한다. 상세 라이선스 안내는 같은 사이트에서 제공하며 작성 코드의 MIT와 게임 유래 자료를 구분한다. 고지는 이용 허락·공식 승인·면책을 주장하지 않는다.

## 브라우저 저장과 준비 안내

판독 중에는 `판독 완료 N / 전체종`과 진행 막대를 표시한다. 전체는 화면에서 읽은 보관함 수량이며, 미확인 시 `—`로 표시한다. 완료 수는 이번 스캔의 최신 관측으로 이름·각성·장수까지 검증한 고유 카드만 센다. 백업과 미판독은 제외하고, 새 관측에서 재확인이 필요하면 수가 줄어들 수 있다. 화면 공유 종료 후 남은 판독 중에도 표시하며, 화면 수집 수와 구분한다. 수량 일치 자체를 스캔 종료 조건으로 사용하지 않는다.

목록은 같은 origin의 IndexedDB 공통 슬롯에 저장한다. 새 탭/브라우저 재실행에서도 복원하며, 주소·프로필이 다르거나 사이트 데이터가 삭제되면 공유되지 않는다. 기존 탭 키가 있으면 해당 백업, 키가 없으면 단일 이전 백업만 이전한다. 여러 이전 백업은 카드 수·경험치를 보여주고 사용자가 복원할 목록을 선택하게 한다. 계정을 임의 선택하지 않는다. 명시적 목록 초기화는 잔여 이전 백업도 비운다.

저장 중·저장됨·실패를 하단과 안내에 표시한다. 저장소 revision을 트랜잭션 안에서 확인하여 오래된 탭의 덮어쓰기와 초기화 후 되살리기를 거부한다. 충돌 시 현재 목록을 CSV로 보관한 다음 저장 목록을 다시 불러온다. 저장 오류만으로 도감·레이드 기능을 잠그지 않는다. 첫 복원이 끝날 때까지 입력 버튼을 잠그고, 로드한 목록 자체를 재저장하지 않는다.

첫 스캔은 화면 검출, 모델 다운로드 실제 수신 MB, 모델 초기화, 병렬 판독 준비를 표시한다. 다운로드 합계는 Content-Length가 있을 때만 표시하고 전체 진행률로 오해할 백분율을 만들지 않는다. 준비 실패·취소는 공유 트랙과 생성한 OCR Worker를 정리한다. 라이선스 안내는 빌드 시 Markdown 표와 링크를 HTML로 렌더링하며 원문 파일도 보존한다.
