# UI 컴포넌트와 테마

## 구성

MUI 9 + Emotion을 사용한다. Tailwind CSS는 도입하지 않는다.
- `src/ui/AppTheme.tsx`: MUI 테마, 시스템 색상 모드, 사용자 선택 저장, 모션 감소 설정.
- `src/ui/WorkspaceNavigation.tsx`: MUI Tabs/Tab, 메뉴 아이콘, 키보드 이동, 활성 패널 연결.
- `src/index.css`: 라이트/다크 공통 의미 색상 변수. 표면·글자·테두리·강조·등급·속성색.
- `src/App.css`: 앱 배치와 카드 그리드. 기능별 CSS도 같은 색상 변수를 사용한다.
- `public/favicon.svg`: 타이틀 로고와 브라우저 탭 아이콘이 함께 사용하는 카드 SVG. 색상과 도형은 이 파일에서만 관리하며 타이틀에서는 배포 base 경로로 참조한다.

데스크톱은 왼쪽 내비게이션과 오른쪽 작업 화면이다. 900px 이하에서는 메뉴가 상단으로 이동한다.
스캔·CSV 입력·목록 초기화는 내 카드 페이지에서만 표시한다. 캡처용 video 요소는 메뉴 전환 시에도 마운트한 채 숨긴다.
카드가 없거나 CSV 판독 중, 스캔 중지·오류 상태에서는 다른 메뉴를 비활성화한다. 인식된 카드가 있으면 스캔 중에도 메뉴를 활성화한다. 정상 CSV·백업 목록도 사용할 수 있다.
보유 경험치 등 요약은 다른 페이지에서도 표시한다. 스크린 캡처 미리보기는 작게 유지한다. 카드 목록의 페이지 크기는 40종이며 기존 반응형 열 수를 유지한다.

판독 중에는 카드 스캔 안에 최근 16개 관측의 썸네일을 가로로 표시한다. 실제 작업 시작·추가 판독·판독됨·확인 필요 상태에 연결하며 기존 JPEG 미리보기를 재사용한다. 고정 폭 카드 한 줄을 Web Animations API의 단일 transform으로 한 칸당 약 240ms로 옮기고 표시 대기열이 쌓이면 최대 100ms까지 빨라진다. 속도는 카드 경계에서만 변경한다. 관측·상태 갱신은 진행 중인 이동을 재시작하지 않는다. 이동 끝에서 DOM과 좌표를 같은 렌더 단계에서 정렬하며 표시 대기열은 최근 16개로 제한한다. 입력이 몰리면 아직 표시하지 않은 오래된 썸네일만 생략하며 인식 작업·결과에는 영향을 주지 않는다. 가로 스크롤바는 만들지 않는다. 마우스 오버·키보드 초점·흐름 멈춤 중에는 표시 카드를 유지한다. 모션 감소 설정에서는 이동·등장 애니메이션을 끈다. 이 줄은 진행 표시이며 전체 인벤토리나 완료 판정의 근거가 아니다.

확인 필요 필터와 접힌 미식별 목록 대신 스캔 요약 아래에 문제 카드를 항상 펼쳐 표시한다. 이름·각성·장수 문제와 판독을 마친 미식별 크롭을 모으며, 처리 대기 중인 미식별은 재관측 대상으로 표시하지 않는다. 검색·등록/미등록 필터와 무관하게 보이고, 해결되면 자동으로 사라진다. 미스캔 떠돌이 상인 카드는 보유 여부 미확인으로 별도 안내한다.

화면 공유/CSV 버튼, 검색·도감 필터 입력, 목록 필터·역할·취약 선택, 지역 아코디언,
비교 설정 팝오버에 MUI를 사용한다. 카드 이미지 그리드·도감 데이터 목록·성장 단계는 전용 컴포넌트를 유지한다.
컴포넌트 스타일은 MUI 테마와 해당 기능 CSS에서 관리하며 전역 일반 버튼 규칙은 MUI를 제외한다.

## 사용 안내

빈 목록에는 성장 탭 열기 → 게임 화면 공유 → 스크롤의 세 단계 안내를 표시한다. 백업을 복원하거나 스캔을 시작하면 접고, 헤더의 사용법 버튼은 모든 메뉴에서 유지한다. 강제로 여는 첫 방문 팝업이나 별도 완료 기록은 만들지 않는다.

MUI Dialog에 준비 대기, 공유 종료와 판독 완료의 차이, 누락·툴팁·검은 화면 대처, 결과 메뉴, CSV와 계정 전환을 안내한다. Esc·닫기와 초점 복귀를 지원한다. 스캔 도중 안내를 열어도 캡처 video와 인식 작업은 유지한다.

## 색상 모드

설정이 없으면 `prefers-color-scheme`을 따른다. 우측 상단 버튼으로 라이트/다크를 전환하면
`loacard-color-mode` 키에 선택을 저장한다. 저장소 접근 실패 시에도 현재 화면에서는 전환한다.
테마 설정은 카드 목록 백업과 별개다. 카드 초기화는 테마 설정에 영향을 주지 않는다.

색상은 `--surface`, `--text`, `--muted`, `--line`, `--accent` 같은 공통 변수를 사용한다.
카드 희귀도와 속성색도 모드별 값을 사용한다. 게임 캡처 이미지 자체는 바꾸지 않는다.

## 검증

화면 변경은 밝은/어두운 모드, 데스크톱/좁은 화면에서 가로 넘침·잘림을 확인한다. 키보드 탭 이동과 메뉴 방향키, Dialog의 Esc·닫기·초점 복귀, 모션 감소 설정을 함께 검사한다. 스캔 진행 중 메뉴 전환, 준비 실패 후 재시도, 진단 저장 중 창 열기와 저장 완료 후 갱신, 파일 검사·재현 취소도 확인한다. 단위 테스트와 빌드 통과가 실제 게임 공유 검증을 대신하지 않는다.

떠돌이 상인·도감작·레이드 카드·진단 화면은 열 때 모듈을 불러오고 로딩 상태를 표시한다. 불러오기 실패 시 오류 안내와 재시도를 제공한다. 인식 엔진 사전 준비와 캡처용 video의 수명은 메뉴 모듈 로딩과 분리한다.

## 미등록 카드 원화

등록 목록도 캡처 이미지가 없으면 카드 ID에 연결된 같은 사이트의 원화 썸네일을 표시한다. CSV에는 이미지 주소를 저장하지 않으며 화면 표시에서만 대체하므로 원화를 실제 스캔 근거로 취급하지 않는다. 스캔 캡처가 있으면 우선한다. 검증된 원화가 없는 카드는 기존 대체 아이콘을 유지한다.

미등록 목록은 이름·등급과 검증된 클라이언트 원화 썸네일을 함께 표시한다. 같은 사이트의 `scanner/artwork/` 파일만 읽으며 외부 이미지 주소를 사용하지 않는다. 파일이 없거나 로드에 실패하면 같은 크기의 대체 아이콘을 표시한다. 이름 툴팁과 이미지 확대의 마우스·키보드 동작은 등록 목록과 같은 컴포넌트를 사용한다. 원화 유무는 보유/미보유 판정 근거가 아니다.

## 하단 고지

모든 메뉴에 비공식·무료·비상업 팬 도구, 제휴·보증 부재와 게임 자료의 권리 귀속을 표시한다. 상세 라이선스 안내는 같은 사이트에서 제공하며 작성 코드의 MIT와 게임 유래 자료를 구분한다. 고지는 이용 허락·공식 승인·면책을 주장하지 않는다.

## 브라우저 저장과 준비 안내

CSV 불러오기 확인 화면에서 보유 카드 경험치를 선택적으로 입력한다. 음수·소수·지수 표기·잘못된 쉼표·안전한 정수 범위 초과는 불러오기를 막는다. 빈칸은 미확인이며 명시적 0과 구별한다. 새 CSV의 카드와 경험치를 함께 적용하고 이전 경험치·성장 이력을 가져오지 않는다. 수동 입력은 최대 보관 용량을 관측한 것이 아니므로 `growthPoints.maximum`은 `null`이다. 현재 값은 도감작·레이드 계산과 브라우저 백업에서 스캔 경험치와 같은 경로로 사용한다. CSV 파일 자체는 세 열을 유지한다.

판독 중에는 `판독 완료 N / 전체종`과 진행 막대를 표시한다. 전체는 화면에서 읽은 보관함 수량이며, 미확인 시 `—`로 표시한다. 완료 수는 이번 스캔의 최신 관측으로 이름·각성·장수까지 검증한 고유 카드만 센다. 백업과 미판독은 제외하고, 새 관측에서 재확인이 필요하면 수가 줄어들 수 있다. 화면 공유 종료 후 남은 판독 중에도 표시하며, 화면 수집 수와 구분한다. 수량 일치 자체를 스캔 종료 조건으로 사용하지 않는다.

목록은 같은 origin의 IndexedDB 공통 슬롯에 저장한다. 새 탭/브라우저 재실행에서도 복원하며, 주소·프로필이 다르거나 사이트 데이터가 삭제되면 공유되지 않는다. 기존 탭 키가 있으면 해당 백업, 키가 없으면 단일 이전 백업만 이전한다. 여러 이전 백업은 카드 수·경험치를 보여주고 사용자가 복원할 목록을 선택하게 한다. 계정을 임의 선택하지 않는다. 명시적 목록 초기화는 잔여 이전 백업도 비운다.

저장 중·저장됨·실패를 하단과 안내에 표시한다. 저장소 revision을 트랜잭션 안에서 확인하여 오래된 탭의 덮어쓰기와 초기화 후 되살리기를 거부한다. 충돌 시 현재 목록을 CSV로 보관한 다음 저장 목록을 다시 불러온다. 저장 오류만으로 도감·레이드 기능을 잠그지 않는다. 첫 복원이 끝날 때까지 입력 버튼을 잠그고, 로드한 목록 자체를 재저장하지 않는다. 목록·경험치·성장 실행 취소·확인 근거만 백업하며 실시간 지도와 전체 검사 로그는 복원하지 않는다. 이전 백업도 읽을 수 있다. 저장소 열기 5초·트랜잭션 8초 한도 뒤에는 재시도할 수 있는 오류를 표시하고, 진단 저장 때문에 카드 목록 사용이나 자동 저장을 늦추지 않는다.

페이지를 열면 인식 엔진을 미리 준비한다. 파일은 캐시에서 읽을 수도 있어 `모델 불러오는 중`으로 표현하고, 이후 세션 생성을 별도로 표시한다. 700ms 미만의 상세 단계는 숨기며 완료·오류는 즉시 알린다. 파일 합계는 Content-Length가 있을 때만 표시한다. 준비 실패·취소는 생성한 OCR Worker를 정리한다. 라이선스 안내는 빌드 시 Markdown 표와 링크를 HTML로 렌더링하며 원문 파일도 보존한다.

판독 상태에는 판독률·남은 종류 수·판독 시작부터 경과 시간을 함께 표시한다. 화면 공유가 끝난 뒤에도 판독, 저장 화면 재검사, 최종 검증, 임시 기록 정리를 구분한다. 카드 판독 100%를 스캔 전체 완료로 표시하지 않는다. 재검사 진행률은 저장 기록 검사 비율이며 카드 판독률과 별개다.

남은 판독 시간은 공유 종료 후 전체 이름이 확보되고 최근 20초 구간에서 최소 5초·3종의 증가가 관측될 때만 범위로 추정한다. 5초 이상 진전이 없거나 완료 수가 감소하면 추정치를 숨긴다. 재검사·검증·정리 및 수집 중에는 시간 추정을 하지 않는다. 추정은 남은 카드 판독 기준이며 추가 검증 시간은 제외한다. 인식 작업을 지연하거나 완료 조건을 완화하지 않는다.

스캔 중 결과 메뉴는 1초 간격으로 최신 카드·경험치를 반영한다. 이름·각성·장수·신뢰 상태가 같으면 계산 입력을 재사용한다. 현재 선택한 메뉴만 계산하고 캡처 video는 계속 마운트한다. 진행 건수와 잠정 결과 안내, 스캔 화면으로 돌아가는 버튼을 제공한다. 성장 완료·실행 취소·자동 저장은 스캔 종료까지 잠근다. 최종 결과는 갱신 간격을 기다리지 않고 반영한다.

## 스캔 진단과 입력 재현

**사용법 → 문제 해결 → 스캔 진단**에서 최근 결과와 문제 이미지를 확인하고 요약 JSON을 저장한다. 기본 요약은 원본 프레임 없이 문제 크롭 최대 32장·인코딩 합계 1MiB만 보관한다. 이미지가 한도에서 제외돼도 제한 내 관측 메타데이터는 유지하며, 요약만으로 입력 재현이 가능하다고 표시하지 않는다. 문제 이미지도 사용자가 직접 확인한 후 외부에 첨부하며 자동 업로드하지 않는다.

**전체 입력 기록 · 문제 재현용**은 기본으로 꺼져 있으며 켠 경우에만 공유 전 기록 Worker를 준비한다. 세션 선택·고정·개별 삭제·내보내기는 진단 창 안에 둔다. 기본 입력 보관 한도는 8개·512MiB이며 고정·진행 중 기록을 보호한다. 저장이 밀리거나 중단된 경우 부분 기록으로 표시하고 알 수 없는 누락 수는 미확인으로 남긴다. `.loareplay`는 입력 재현용이고 요약 JSON은 진단용이다. 원래 실행 기록 확인은 당시 이벤트를 같은 규칙으로 재생하는 검사이며 재판독 결과와 구분한다. 무손실 여부·누락 프레임·픽셀 검증 진행·원래 결과와의 차이를 표시하고, 이전 영상 기록은 압축 영상 기반 재현으로 명시한다.

진단 저장은 스캔 종료와 별도로 진행한다. 저장 중 열린 창에는 `진단 기록 저장 중…`을 표시하고 파일 불러오기·삭제·재현·내보내기를 비활성화한다. 저장이 끝나면 열린 창의 최근 기록을 갱신한다. 수동으로 불러온 파일은 추가 갱신 없이 유지한다.

불러오기·실행 기록 검사·재현은 작업 중지, Esc 또는 닫기로 취소할 수 있다. 닫은 작업의 늦은 결과는 표시하지 않는다. 불러오기·삭제 30초, 이벤트 검사 120초, 재현 10분 한도를 안내하며 브라우저 전체 실행 정지 중에는 타이머도 지연될 수 있다. 재현 중지 시 부분 결과를 완료 비교로 표시하지 않고 기존 내 카드 목록·백업을 유지한다.

## 게임 위 스캔 진행 창

지도와 최근 수집 상태는 `판독 대기`·`판독 중`·`완료`를 구분한다. 대기는 회청색, 판독 중은 밝은 파랑과 작은 점으로 표시하고 실제 판독 중인 칸만 약하게 점멸한다. 완료는 녹색 체크로 유지한다. 모션 감소 설정에서는 점멸을 끈다. 최근 화면 밖의 처리도 알 수 있도록 전체 `판독 대기 N건 · 판독 중 N건`을 별도로 표시한다. 이는 관측 작업 수이며 카드 완료 종류 수와 다르다. 대기·판독 수가 0일 때도 표시하여 작업이 끝났는지 확인할 수 있게 한다.

완료된 지도는 이름순 복원 외에도 안정된 화면들에 함께 나온 카드들의 상대 위치를 연결해 보완한다. 이 연결은 검증된 카드 ID와 관측 간격으로만 복원하며, 전체 판독 완료와 위치 연결 건수를 구분해 표시한다. 이름순을 포함한 정렬 방식이 바뀌면 이전 상대 위치는 폐기한다. 불확실한 위치는 그대로 남기고 카드 수만으로 임의 채우지 않는다.

내 카드의 진행 창 띄우기는 지원 브라우저에서 Document Picture-in-Picture를 사용자 클릭으로 연다. 미지원 또는 열기 실패 시 같은 패널을 페이지에 표시한다. 최대 보관함 550칸을 10열×55행의 작은 네모 지도로 표시하고, 현재 보이는 4행은 테두리가 위아래로 이동한다. 전체 행 번호를 사용하며 절대 행 번호는 카드·손잡이가 함께 안정된 맨 위/아래 화면에서 시작하고, 획득 단계가 이미 묶은 동일 관측 그룹이 6개 이상의 같은 열에서 일치하는 행을 대조해 추적한다. 다른 행을 지지하는 열이 3개 이상이면 연결하지 않는다. 관측 그룹이 달라도 이름이 검증된 카드 ID가 같으면 과거 프레임의 위치를 재연결한다. 늦게 연결된 프레임은 최신 위치 상태나 현재 화면을 덮어쓰지 않는다. 스크롤바는 후보 범위를 제한하는 보조 근거다. 독립적으로 대조한 두 위치의 오차가 일치하고 정수 행에 충분히 가까울 때만 겹치지 않는 구간의 위치를 보정한다. 이 추정 결과로 보정 기준을 다시 학습하지 않는다. 이름순 스캔이 완전히 검증되면 등록 카드의 정렬 순서를 독립적으로 위치를 확인한 두 행 이상·20개 이상의 카드와 비교한다. 이 순서가 모두 일치할 때만 대기 프레임을 다시 연결하며, 각 프레임에서도 같은 열 여섯 개 이상의 일치가 필요하다. 중간에서 시작했거나 정렬/행 근거가 부족하면 위치를 단정하지 않는다. 55행 전체 범위의 이동은 51단계(0~51)다. 보유 종류 수와 개방 용량, 최대 슬롯 수는 서로 다른 값이다. 상단 용량으로 확인한 잠금 슬롯과 관측한 빈 슬롯은 같은 비활성 모양의 카드 없음으로 표시한다. 범례와 툴팁도 통일하며, 아직 위치를 확인하지 않은 슬롯은 별도로 유지한다. 판독 완료 목표는 이번 실행의 등록 카드 수다.

각 위치의 입력·완료·재관측 상태는 화면 밖으로 이동해도 유지한다. 다음 프레임의 임시 미확인이나 가림은 이미 연결된 관측 기록을 지우지 않으며, 새 관측 그룹이 연결되면 최신 상태로 갱신한다. 현재 화면의 가림 상태는 별도로 유지한다. 지도에 위치 기록이 없다는 것은 카드 미판독이나 실제 빈 슬롯을 뜻하지 않는다. 완료 후에는 현재 위치를 계속 찾는 문구 대신 위치 기록으로 표시한다. 최종 수량과 최신 필드 검증을 통과하면 카드 ID가 확인된 과거 관측의 재확인 표시도 완료로 맞춘다. 같은 정렬 구간에서 독립적으로 식별한 위치 이력은 뒤의 미식별 크롭에도 보존하되, 다른 카드 ID나 명시적 빈칸이 관측되면 교체한다. 판독 중에는 이 이력으로 새 관측의 미확인을 덮지 않는다. 식별하지 못한 카드나 종류 수만으로 위치를 채우지 않는다. 전체 등록 카드의 판독이 완료되고 이름순 정렬이 실제 위치가 확인된 모든 카드와 일치할 때에는 그 카드 ID 목록으로 최종 위치를 복원한다. 이는 프레임 획득 성공을 뜻하지 않으며 UI와 칸 툴팁에 이름순 복원임을 표시한다. 이름순 이외의 정렬이나 검증 불일치에서는 이 복원을 사용하지 않는다. 표시용 그룹과 최신 작업 ID를 연결하여 늦은 응답이 최신 입력을 완료로 바꾸지 않게 한다. 정렬 키 또는 확인된 방향이 실제로 바뀌면 위치 지도·대기 프레임·정렬 복원 근거만 비운다. 같은 관측 그룹의 판독 상태·카드 ID·진행 중 작업 연결은 유지하여 중복 입력도 완료 상태를 이어받는다. 새 관측은 기존처럼 대기로 전환하며 이전 작업의 늦은 완료로 확정하지 않는다. 방향 화살표를 잠깐 읽지 못하면 마지막으로 확인한 같은 정렬 키의 방향을 유지하며, 미확인 방향을 처음 읽은 경우에도 지도를 초기화하지 않는다. 정렬 키 자체가 바뀌면 이전 키의 방향을 가져오지 않는다. 새 스캔의 전체 초기화는 위치와 판독 상태를 모두 지운다. 모든 현재 칸이 확보됐거나 명시적 빈칸이면 다음 구간 안내를 표시하지만, 이는 최종 판독 성공을 보장하지 않는다. 추가 OCR·픽셀 복사 없이 기존 상태 발행을 사용한다. 최대 550개 위치, 256개 대기 프레임의 칸 메타데이터와 제한된 관측 그룹/카드 ID 연결만 보관한다. 이동 효과는 reduced-motion 설정에서 끈다.

진행 창은 게임 카드 영역 밖에 놓는다. 전체 화면 공유에서는 진행 창도 입력에 포함될 수 있다. 독점 전체화면 위의 표시와 내장 브라우저의 PiP 지원은 실제 환경에서 확인한다.

위치 표시 갱신은 판독 대기열과 분리한다. 기존 프레임에서 읽은 스크롤바와 최대 51단계 이동 범위로 현재 4행의 추정 위치를 즉시 계산하고, 일관된 독립 위치 보정치가 있으면 적용한다. 추정은 점선과 ‘약’으로 표시하며 카드 대조가 끝나면 실선의 확정 위치로 바뀐다. 스크롤바만 최소 32ms 간격으로 확인하고 진행창 전용 저장소로 발행한다. 위치는 보간 지연 없이 최신 추정으로 이동하고, 칸 색상 전환은 50ms로 제한한다. 본문 판독 숫자와 진행창은 같은 경량 저장소를 구독하며, 전체 목록 렌더링과 별도로 갱신한다. 추정 위치는 지도 슬롯 등록·판독 완료·자동 종료의 근거가 아니다. 카드 창이나 스크롤 범위를 읽지 못하면 추정도 지운다.

스크롤 양 끝에서도 독립적으로 확인한 카드 위치·검증된 이름순과 모순되면 등록을 보류한다. 움직이는 카드보다 손잡이가 먼저 끝에 도착하면 위치 강조만 이동하고 슬롯을 확정하지 않는다. 이후 안정된 끝점은 스크롤바만으로 예측했던 임시 위치를 수정할 수 있다. 열 불일치와 후보 범위를 벗어난 위치도 이 검사를 우회할 수 없다. 표시용 관측 캐시 정리 시 현재 화면·최대 550칸 지도·최대 256개 대기 프레임에서 참조하는 상태를 보존한다. 그 외 오래된 상태만 정리하고, 참조 순회는 256개 단위로 나눠 반복 비용을 줄인다. 작업 연결은 그룹의 최신 판독 작업 하나만 유지하며 중복 프레임이 진행 중 작업 연결을 밀어내지 않는다.

화면 공유에서는 스크롤바 전용 경로가 카드 획득/OCR보다 앞서 현재 위치를 표시한다. 늦게 끝난 카드 프레임이 이 표시를 되돌리지 않으며, 현재 스크롤 위치와 해당 카드 프레임의 위치가 다르면 ‘아래로 스크롤하세요’ 안내도 보류한다. 전체 픽셀 복사 대신 16×942 픽셀의 작은 영역만 읽고 같은 영역의 고정 화살표로 창 이동·가림을 검사한다. 좌표는 현재 화살표 픽셀이 일치하는 동안 재사용한다. 모양이 달라지면 즉시 표시를 숨기고 2초간 재확인한 뒤 계속 다르면 폐기한다. 해상도 변화·픽셀 읽기 실패는 즉시 좌표를 폐기한다. 위치 표시가 무효화되면 과거 위치를 현재 위치처럼 다시 표시하지 않는다.
