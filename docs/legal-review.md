# 공개 배포 권리 검토

검토일: 2026-10-08. 대한민국 서비스와 현재 저장소·정적 웹 빌드를 대상으로 한 기술·문서 검토다. 법률 의견서, 권리자의 승인, 모든 특허·상표의 권리조사를 대신하지 않는다. 허가가 확인되지 않았다는 사실과 위법하다는 판단은 구분한다.

## 결론과 공개 범위

비상업적 팬 애플리케이션에 적용할 수 있는 공식 UGC 허용 근거가 있다. 그러나 현재 게임 유래 자료 전체의 재배포 권한은 확인되지 않았다. 작성 코드의 MIT와 외부 자료의 이용 조건을 분리한다. 모든 파일을 MIT로 재허가하거나 전체 앱의 공개 적법성이 확인됐다고 설명하면 안 된다.

| 대상 | 확인 내용 | 판단 / 남은 일 |
|---|---|---|
| 작성한 React/TypeScript/Python 코드 | 작성 코드·문서에 MIT, 외부 자료는 제외 | 외부 코드의 실질적 복제 여부까지 전수 증명한 것은 아님 |
| 화면 공유 스캐너 | 브라우저 pixels/Worker, 화면의 외부 OCR 전송 경로 없음 | UGC 근거가 있으나 공식 승인 도구 또는 제재 면제를 뜻하지 않음 |
| 게임 UI PNG 2개, 인식 특징·픽셀 | `public/scanner`에 포함, 일반 빌드에서 `dist`로 복사 | 필요한 최소한의 사용인지 및 UGC에 따른 배포 범위를 권리자에게 확인 |
| 게임 화면 기반 테스트 자료 | `tests/fixtures`의 rgba/gray/압축 픽셀·마스크 포함 | 웹 배포와 별개로 공개 Git 저장소도 배포임. 승인 또는 합성 자료 대체 검토 |
| 성장·레이드 마스터 | 클라이언트 DB를 읽는 생성기로 만든 데이터 | 추출 과정, 공개된 정보만 포함하는지, 파생 데이터 배포 권한 확인 |
| 클라이언트 기반 카드 자료 | 420종 메타데이터 DB 대조, 원화 특징 388종·표시 썸네일 420종 | 외부 그림 픽셀은 제거했지만 과거 라벨 대응 이력은 보존. 게임 원화 배포 권리 확인은 별도 |
| 외부 소프트웨어·모델 | npm 고지, MPL 소스, 추가 라이선스 원문 제공 | 아래 버전별 점검을 유지. 전체 네이티브 바이너리 SBOM 검증까지 완료한 것은 아님 |

게임 유래 자료를 제외한 코드 중심 배포는 가능한 대안이지만, 현재 앱은 그 자료를 사용한다. 파일만 지우면 동일 기능·테스트가 유지된다고 가정하지 않는다. 승인된 자료 또는 직접 검증한 공개 정보와 합성 fixture로 대체한 후 다시 검사해야 한다.

## 공식 규정

- [로스트아크 UGC 규약](https://clause.onstove.com/stove/terms?category=LATERMSUGC6&only_game=Y&game_id=LA_TERMS_UGC6): 본문 시행일 2026-01-01. 2항은 애플리케이션을 UGC에 포함하며, 3~5항은 조건을 지킨 비상업적 창작·무료 공유와 권리 귀속을 정한다. 회사·제3자의 기존 권리는 유지된다. 수익 활동에는 원칙적 사전 승인과 일부 플랫폼 광고·순수 후원 예외가 있으므로, 웹앱의 광고·유료 기능까지 자동 허용된 것으로 넓혀 해석하지 않는다. 공식 콘텐츠 오인, 승인 없는 공식 로고·상표 사용 및 명칭을 포함한 주소 등록에 관한 제한도 있다.
- [서비스 이용약관](https://clause.onstove.com/stove/terms?category=service&game_id=45&only_game=Y): 13조의 비승인 프로그램·권한 없는 클라이언트 변경 제한, 21조의 콘텐츠 권리 귀속과 이용 조건을 함께 검토한다. UGC 규약에는 회사 규정과 충돌할 때의 우선 규정도 있으므로 한 문장만으로 모든 팬 프로그램이 금지 또는 승인됐다고 단정하지 않는다.
- [운영정책](https://clause.onstove.com/stove/terms?category=oppolicy&game_id=45&only_game=Y): 본문 시행일 2025-07-30. 데이터 조작·추출 항목은 통신 흐름 조작과 클라이언트 분석에 의한 미공개 정보 추출을 다룬다. 자동 조작·서비스 간섭 프로그램에 관한 제한도 있다. 현재 화면 스캔과 데이터 생성 과정은 별도로 판단한다. DB 유래라는 이유만으로 미공개 정보라고 단정하지 않으며 420종·259개 도감의 공개 여부를 전수 입증한 상태도 아니다.

규정 원문은 공식 홈페이지 footer에서 연결되는 한국 서비스 페이지를 브라우저로 읽었다. JavaScript 없는 검색 도구에서 본문이 나오지 않는 경우에도 영문/해외 서비스 약관으로 대체하지 않았다. 약관상 제재 가능성과 법률상 책임은 별개다.

## 외부 데이터·추출 방식

- [인벤 카드 DB](https://lostark.inven.co.kr/dataninfo/card/) footer는 콘텐츠의 무단 전재·복사·배포를 금지한다고 안내한다. 공개 접근 가능하다는 사실은 수집·재배포 허가가 아니다. 모든 개별 수치에 인벤 저작권이 있다는 뜻도 아니다. 현재 원화 픽셀은 클라이언트 atlas와 게임 화면 기반 자료로 대체했다. 과거 이름-원화 대응에 참고한 이력은 보존하며, 대체만으로 모든 권리 쟁점이 해소됐다고 판단하지 않는다.
- [Lost Ark Codex 카드 DB](https://lostarkcodex.com/kr/cards/)와 [연락처](https://lostarkcodex.com/kr/contacts/)에서 이번 검토 범위의 일괄 데이터·이미지 재배포 허가를 확인하지 못했다. 개인정보처리방침이나 robots 정책을 저작권 이용허락으로 사용하지 않는다.
- `build-growth-data.py`, `build-raid-data.py`는 로컬 SQLite DB를 읽고 마스터를 만든다. DB 해시는 동일 입력을 확인할 뿐 적법한 취득·재배포를 증명하지 않는다. 원본 DB·복호화 키·게임 폰트·게임 아카이브는 현재 추적 파일에 없다.
- [lostark-explorer의 고정 리비전](https://github.com/Poyoanon/lostark-explorer/tree/dda4e63d50cb68dae71e224767e7e97a2fda6896)은 MIT다. 이 도구의 라이선스가 게임 데이터의 추출·재배포까지 허락하지는 않는다. 추출기 코드는 현재 저장소의 정상 빌드 구성에 포함되지 않는다.
- [meter-core](https://github.com/lost-ark-dev/meter-core)는 현재 루트에 LICENSE와 package.json의 license 선언이 확인되지 않았다. 생성기는 이를 enum 숫자 대조 출처로 기록하며 전체 구현을 가져오지는 않는다. 공개 저장소라는 이유로 코드를 복사하지 않는다. 숫자 대응은 공식 공개 정보 또는 게임 화면에서 독립 검증하고 출처를 보완하는 편이 좋다.

[저작권법 제35조의5](https://www.law.go.kr/법령/저작권법/제35조의5)는 이용 목적·저작물 성격·사용 분량·시장 영향을 함께 고려한다. 비영리 또는 작은 이미지라는 한 가지 사유로 공정 이용을 확정하지 않는다. [제93조](https://www.law.go.kr/법령/저작권법/제93조)는 개별 소재와 데이터베이스의 상당 부분 또는 반복·체계적 이용을 구분한다. [제104조의2](https://www.law.go.kr/법령/저작권법/제104조의2)는 기술적 보호조치와 예외를 정하므로, 암호화된 자료의 접근·추출 과정은 결과물 배포와 따로 검토한다. 실제 보호조치의 성격과 예외 적용을 이 보고서에서 확정하지 않는다. 현행 법령 화면의 시행일은 2026-08-11이다.

비교상 화면 인식·계산·정적 호스팅 자체는 이미 공개 사례가 있는 접근이다. 이는 개발 방향의 참고가 되지만 개별 이미지나 DB의 취득·재배포 권한까지 이전하지 않는다. 공식 UGC의 일반 허용 조건에 부합하는 이용마다 별도의 개별 승인을 반드시 받아야 한다고 단정하지 않는다. 현재 추가로 확인할 핵심은 LoaCard에 포함된 자료의 출처와 해당 조건의 적용 범위다.

## 현재 공개 대상 데이터의 실물 목록

현재 작업 트리에서 존재하는 Git 추적 파일과 ignore되지 않은 신규 파일을 기준으로 확인했다. 삭제 예정 파일과 Git 과거 이력은 이 목록에 포함하지 않는다. `public/` 자료는 정적 배포에도 복사되며, `tests/fixtures/`는 웹 빌드에서 제외되어도 저장소 공개 시 전달된다.

|---|---|---|
| `public/scanner/cards.json` | 420종 이름·ID·등급·출처와 원화에서 만든 `feature` | 우선 검토. 단순 카드 목록만 있는 파일이 아님. 클라이언트 DB로 검증한 메타데이터와 원화 파생값을 분리해서 판단. 미사용 뒷면 특징과 외부 아이콘 경로는 제거 |

| `public/raid/master.json` | 93종 카드와 19개 레이드 세트, 구성·속성·단계 효과 | 위와 같은 DB 파생 자료. 원본 DB 파일은 아니지만 출처가 제거되는 것은 아님 |
| `src/features/merchants/merchants.json` | 사용자 제공 기획 자료에서 정리한 22개 지역/상인 그룹과 판매 카드 | 개별 사실관계 자료 중심. 최초 원자료의 출처 보완·현재 게임 내용과 독립 검증 권장 |
| `tests/fixtures/` | 19개 JSON, 합계 3,355,415바이트. 카드 크롭 RGBA, 회색조, 이름 마스크, 스크롤바 압축 픽셀, 보유량 수동 정답 등 | 게임 유래 표본은 우선 검토. 이름 가시성 마스크는 36개만 유지하며 옛 이름·장수 사전은 제거. 합성 `observation-plans.json`도 함께 집계한 크기다. 실제 RGBA/base64/zlib 표본을 복원하면 게임 화면 일부가 나옴. 합성 표본 대체 또는 허용 범위 확인을 검토하되 실제 화면의 가림·압축 회귀를 잃지 않도록 함 |

이 목록의 우선순위는 검토 순서이며 위법 판정이나 정량적 법률 위험 점수가 아니다. 원화·UI 표현을 보존한 픽셀, 개별 숫자·사실 정보, 데이터베이스의 체계적 이용은 각각 다른 쟁점이다.

미사용 자료 정리에서는 헤더 숫자·ORB·옛 숫자·중복 장수 atlas 4개와 외부 원화 다운로드 스크립트 2개를 제거했다. 뒷면 특징·아이콘 경로·미사용 보석 표본 33개도 제외해 해당 파일 묶음을 2,967,347바이트 줄였다. 중복 장수 검사는 실제 런타임 atlas로 통합했고, 삭제한 옛 데이터 자체를 확인하던 테스트 2개를 제거했다. 남은 테스트 376개·lint·build가 통과했다. 실제 사용하는 카드 특징·메타데이터와 보석 2개의 값이 정리 전과 같음을 대조했다. 이번 정리에서 전체 영상·실시간 화면 공유를 새로 실행하지는 않았다. 남은 게임 유래 자료의 권리 확인까지 완료한 것은 아니다.

추가 정리에서는 옛 식별 판정 코드·전용 테스트, 이름/장수 사전, 클라이언트 에셋 비교 실험과 과거 생성 도구를 제거했다. 이름 가시성 검사는 형태 기준으로 선정한 29개와 별도 크롭 7개를 합친 36개 표본으로 유지한다. 테스트 fixture는 19개 JSON으로 줄었고, 전체 테스트 371개·lint·build가 통과했다. 이번 추가 정리 전후 런타임 자료 16개 파일의 SHA-256 및 배포 복사본이 일치했다. 표본 축소는 전체 카드 정확도 검증이나 게임 유래 자료의 재배포 허가를 뜻하지 않는다.

현재 공개 대상의 이미지 파일에는 직접 작성한 `public/favicon.svg`, 위 PNG 두 개와 클라이언트 원화 썸네일 420개(`public/scanner/artwork/*.webp`)가 포함된다. 그러나 JSON의 픽셀까지 없다는 의미는 아니다. 원본 전체 atlas·게임 DB·게임 폰트·아카이브·전체 영상은 공개 대상에서 제외한다. 로컬 자료는 `work/`, `fixtures/local/`에 분리되어 있다. 과거 커밋 전체의 포함 여부를 이 검사로 보장하지 않는다.

Paddle 문자표는 저장소에 포함된 외부 소프트웨어 자료다. OpenCV.js 실행 파일은 저장소의 중복 복사본을 제거하고 설치된 npm 패키지에서 SHA-256 검증 후 `public/ocr/opencv.js`로 생성한다. 웹 배포에는 그대로 포함되므로 관련 고지를 유지한다. ONNX 모델·Tesseract 언어 데이터/Worker 등 `public/ocr/`는 Git에서 제외되지만 준비 스크립트가 다운로드해 웹 배포에 포함한다. 게임 자료와 달리 공개 라이선스와 버전별 고지를 중심으로 관리한다. 개발용 수집·DB 변환 스크립트도 저장소에 있으므로 로컬 원본이 빠졌다는 이유로 자료 취득 방법까지 검토 대상에서 제외하지 않는다.

## 소프트웨어 점검과 보완

1. `package-lock.json`의 production 의존성 120개를 목록화했다. MIT/BSD/ISC/Apache-2.0/MPL-2.0 선언을 확인했다. 이 수는 실제 웹 번들 구성 수가 아니며 네이티브 하위 코드를 모두 포함한 수도 아니다.
2. `guid-typescript@1.0.9`, `tr46@0.0.3`은 ISC/MIT 선언은 있으나 원문 누락이 남아 있다. npm gitHead를 조사했고 tr46 해당 커밋에도 원문이 없었다. guid 해당 커밋은 현재 upstream에서 조회되지 않았다. 임의로 저작권자·연도를 만들어 원문을 채우지 않았다.
3. 현재 Vite 빌드의 앱/Worker 모듈 549개와 `ort.wasm.bundle.min.mjs.map`, Tesseract `worker.min.js.map`에서 이 두 패키지 경로는 발견되지 않았다. 현재 정적 배포의 포함 근거가 없는 항목으로 분류하되 누락 보고서는 유지한다. Node 실행 파일·다른 ONNX 백엔드로 전환하면 재검토한다.
4. Tesseract 워커에 이미 포함된 `buffer@6.0.3`, `base64-js@1.5.1`, `ieee754@1.2.1`은 앱 lockfile에 없었다. Tesseract 6.0.1의 npm gitHead `9d9b666ad5d253451857f4085763e2a9586e984f` lockfile → npm integrity → 워커 source map 소스 일치를 검증해 원문을 확보했다. 워커의 원본 `.LICENSE.txt`도 같은 경로로 복사하도록 수정했다.
5. [ONNX Runtime 1.30.0 ThirdPartyNotices](https://github.com/microsoft/onnxruntime/blob/v1.30.0/ThirdPartyNotices.txt), Tesseract core 6.1.2의 고정 submodule 라이선스 9개, OpenCV 5.0.0의 protobuf/zlib/flatbuffers, tessdata 4.1.0 모델 원문과 Google Material Icons 원문을 추가했다. 총 19개 추가 원문을 해시와 출처로 관리한다. OpenCV 실제 파일은 설치 패키지와 바이트가 같고 build information에서 버전과 하위 라이브러리를 확인했다.
6. Mediabunny 1.61.1의 설치된 원본 소스 70개 파일과 MPL 원문을 배포 페이지에서 제공한다. [Mozilla FAQ Q8·Q11·Q16·Q17](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)에 따라 브라우저에 전달되는 minified JavaScript의 소스 제공과 파일 단위 적용 범위를 구분한다.
7. PaddlePaddle 공식 [한국어 v5 모델](https://huggingface.co/PaddlePaddle/korean_PP-OCRv5_mobile_rec_onnx)과 [숫자용 v6 모델](https://huggingface.co/PaddlePaddle/PP-OCRv6_tiny_rec_onnx)은 Apache-2.0으로 표시된다. 모델과 문자표의 고정 리비전·해시를 유지한다. 라이선스 선언 확인은 학습 데이터 전체의 권리 검증을 의미하지 않는다.
8. `ffmpeg-static`은 로컬 입력 준비용 개발 의존성이다. FFmpeg 실행 파일은 Git/정적 배포에 포함하지 않는다. 추후 다운로드 패키지에 넣으면 해당 바이너리의 GPL/LGPL 및 구성별 조건을 별도로 확인한다.

추가 고지는 [manifest](../licenses/third-party/manifest.json)에 있으며 생성기가 패키지 버전·고지 해시·워커 내부 소스를 검사한다. 상위 프로젝트의 전체 고지는 웹 빌드에 없는 구성도 포함할 수 있다. 자체 재빌드로 네이티브 링크 대상 전체를 대조한 감사나 특허 검토는 수행하지 않았다. 상세 설치/생성 절차는 [데이터 유지보수](data-maintenance.md)를 따른다.

## 개인정보·브랜드

`src`의 통신 지점과 OCR 경로 설정을 검사했다. 화면과 CSV를 외부 OCR/분석 서버에 업로드하는 경로, 분석용 beacon, 로그인·결제 기능은 발견되지 않았다. OCR 모델과 Worker는 같은 사이트에서 읽는다. 테마는 localStorage, 스캔 백업·개발 기록은 브라우저 저장소를 사용하므로 공용 PC에서는 사이트 데이터 삭제가 필요할 수 있다. 이 검사는 모든 외부 바이너리의 동작에 대한 보안 감사를 대신하지 않는다.

GitHub Pages는 [공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)에 따라 방문자의 IP를 보안 목적으로 기록한다. 따라서 화면을 업로드하지 않는다는 설명은 가능하지만 서비스 전체에서 개인정보가 전혀 처리되지 않는다고 표현하지 않는다. 이후 서버 저장·분석 도구·오류 수집을 추가하면 개인정보 처리방침과 처리 근거를 다시 검토한다.

게임 폰트 파일은 배포하지 않고 시스템 글꼴을 사용한다. LoaCard가 공식 서비스로 보이지 않게 비공식 표시를 유지한다. LoaCard 명칭에 대한 국내외 등록상표 전수 검색은 하지 않았으므로 독점 사용 가능성을 보장하지 않는다.

초기 템플릿에서 남은 favicon은 직접 작성한 단순 카드 SVG로 교체했다. 참조가 없는 소셜/템플릿 로고 묶음 `public/icons.svg`도 배포 대상에서 제거했다. 실제 UI의 MUI/Google 아이콘은 해당 고지를 유지한다.

## 운영 방침 (2026-10-08)

개별 사전 문의는 진행하지 않는다. 무료·비상업 팬 도구로 운영하며 원본 DB·폰트·아카이브·전체 영상은 제외하고 기능에 사용하는 가공 자료만 포함한다. 이 선택은 개별 승인 확보나 모든 자료의 배포 권한 확인을 뜻하지 않는다. 위 검토의 미확인 사항은 그대로 유지한다.

모든 화면 하단에 비공식·비상업 운영, 제휴·보증 부재, 게임 이미지·데이터의 권리 귀속을 표시하고 상세 라이선스 안내로 연결한다. 작성 코드·문서만 MIT로 제공하며 게임 유래 자료와 외부 소프트웨어는 각각의 권리를 유지한다. 고지를 이용 허락이나 면책으로 표현하지 않는다.

현재 배포에서 인벤/Codex 그림 픽셀은 제외했지만 과거 라벨 연결에 참고한 출처 이력은 남긴다. 향후 자료 추가·수익화·공식적인 오인 가능성이 있는 변경은 적용 조건을 다시 검토한다.

## 검증 범위

재현 명령: `npm ci`, `npm run lint`, `npm test`, `npm run build`, `npm run audit:distribution`. 최초 권리 검토 시 테스트 378개, 미사용 코드·자료 정리 시 371개가 통과했다. 클라이언트 원화 전환과 떠돌이 상인 시간표를 추가한 뒤에는 376개다. 배포 폴더의 추가 고지 원문·manifest 해시, 워커 원본 고지, Mediabunny 소스 포함도 별도로 확인한다. 빌드의 기존 500 kB 초과 번들 경고는 라이선스 판정과 무관하다.

현재 작업 트리와 생성한 정적 배포물을 검사했다. 원본 DB·영상·폰트·실행 파일의 추적 여부, 소스의 외부 요청 경로, 게임 자료의 출처, 직접·간접 의존성 및 사전 빌드된 주요 OCR 코드를 확인했다. Git 과거 전체 이력의 권리 관계, 모든 테스트 픽셀의 수작업 개인정보 검수, 420종 카드의 공개 여부 전수 확인은 이번 검토에 포함하지 않았다. 저장소 이력이나 공개 여부를 바꿔도 원자료의 권리 관계는 바뀌지 않는다.
