# 떠돌이 상인

지역별로 5각 재료가 남았는지 확인해 게임에서 알림을 설정하는 참고 화면이다. 외부 알림 서비스나 게임 설정을 읽거나 바꾸지 않는다.

`src/features/merchants/merchants.json`의 22개 지역·상인/133종을 사용한다. 최초 사용자 제공 설계안의 판매 목록을 전사한 자료로, 자동 최신 동기화 목록은 아니다. 루테란 동부1/모리스와 동부2/버트는 별개다. 갱신은 [데이터 유지보수](data-maintenance.md)를 따른다.

등록된 카드의 부족 장수는 `15 - 각수*(각수+1)/2 - 추가 장수`다. 4각 2장은 3장 부족하고 4각 5장은 재료 확보 상태다. 실제 5각 완료와 재료 확보를 구분한다.

- 수집 필요: 부족한 판매 카드가 하나 이상 확인된 지역.
- 수집 완료: 모든 판매 카드의 재료 확보를 확인했고 스캔이 종료된 지역.
- 내부 unknown: 누락·판독 불확실 또는 스캔 중. 미스캔을 미보유/16장 부족으로 추정하지 않는다.

이름·장수·각성 오류와 불가능한 조합을 확정 입력에서 제외한다. 확인 대상은 내 카드에서 다시 스캔하도록 안내한다. 메인 UI에서는 카드 판독이 끝나고 usable 목록이 있을 때 메뉴를 활성화한다. 지역 상세는 판매 카드와 부족 수를 보여 주며 사용자가 필요한 지역의 게임 알림을 직접 켠다.

`merchant-progress.test.ts`가 카탈로그 ID·이름 연결, 부족 장수, 미확인 입력, 스캔 중 완료 방지, 유사 이름 분리와 복사 문자열을 검사한다.

## 등장 시간 안내

`merchant-schedule.ts`에서 한국 시간(UTC+9) 기준 고정 주기를 계산한다. 매일 04/10/16/22시 중 지역별 두 회차, 회당 5시간 30분이다. 상단은 오늘 네 회차와 현재 종료/다음 등장까지 남은 시간을 표시하고, 지역별 요약에는 현재 판매 시간 또는 다음 등장 시각을 표시한다. 지역 상세에는 오늘 두 회차를 표시한다. 15초마다 갱신하며 탭 복귀 시 즉시 갱신한다.

22시 회차는 **등장한 날의 요일 그룹**으로 다음 날 03:30까지 유지한다. 시작 시각 포함, 종료 시각 제외이며 각 회차 사이 30분은 판매 시간이 아니다. 해외 PC에서도 한국 달력으로 계산한다. 상인의 등장 예정과 실제 판매 카드·구매 완료 여부를 구분하며, 서버 판매 정보 수집이나 니나브 서버 자동 추적은 구현하지 않는다. 실제 판매 품목은 게임에서 확인한다.

2026-10-08 사용자 제공 요일표를 적용했다. 아래 오전 그룹은 04/16시이며, 나머지 그룹은 10/22시에 등장한다.

| 화 | 2, 3 |

근거: [2023-08-02 업데이트 공지 전재](https://www.inven.co.kr/board/lostark/4820/4855)의 기본 회차/지속 시간, [2025-01-09 림레이크 상인 관측 기록](https://www.inven.co.kr/board/lostark/4821/103298)의 1그룹 편성. 요일표 전체를 2026년 공식 공지로 재확인한 것은 아니다. 규칙 변경 시 출처·그룹을 함께 갱신한다. 시간표는 일반 대륙 상인에만 적용하며 해양/섬 특수 상인에 자동 확장하지 않는다.

`merchant-schedule.test.ts`가 22개 지역의 일 2회 편성, 루테란 동부 두 상인 구분, 자정/연말/요일 전환, 시작·종료 경계와 30분 공백을 검사한다.
