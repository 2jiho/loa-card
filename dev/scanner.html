비교 전 npm run corpus -- verify로 저장한 원본을 검사하세요. 재현 파일은 다시 읽기 전에 파일 전체 SHA를 자동 확인합니다. 일반 영상·사진 검사에는 해시 재계산이 없으며 입력 비교 모드는 실제 사용할 원본 Blob의 SHA를 확인합니다. 사진은 등록·선택 순서를 유지하며 결과를 정답으로 자동 등록하지 않습니다.

1배속 검사는 영상의 captureStream으로 실제 공유와 같은 수집·병렬 판독 경로를 실행합니다. OS 캡처 시각과 모든 원본 프레임 도착을 재현하지는 않습니다. 사진·재현 파일은 순차 검사만 지원합니다. 재현 파일은 저장된 픽셀과 설정을 사용하며 원래 처리 속도를 재현하지 않습니다. 현재 실행 상태 재생은 별도 상태 이벤트의 해시 검사이며 저장 세션 입력의 완전성 검사를 대신하지 않습니다.

판독 크롭 기록은 이 기기의 브라우저 내부에 저장되며 브라우저 데이터 정리로 사라질 수 있습니다. 개발용 크롭 파일 내보내기는 브라우저의 스트리밍 저장 선택기가 필요합니다. 새 기록은 판독 직전의 후보 크롭을 보존합니다. 이전 v1 기록은 판독 종료 후 저장되어 입력과 일치하는지 확인할 수 없습니다. 무결성 검사는 저장된 픽셀과 호출 기록만 확인하며 원본 화면, 획득·제외된 카드, 스크롤 누락이나 실제 처리 속도는 재현하지 않습니다. 기록 한도 또는 손실 시 부분 기록으로 표시합니다.
