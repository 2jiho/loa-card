입력 코퍼스를 읽고 있습니다.

비교 전 npm run corpus -- verify로 저장한 원본을 검사하세요. 일반 검사에는 해시 재계산이 없으며 입력 비교 모드는 실제 사용할 원본 Blob의 SHA를 확인합니다. 사진은 등록·선택 순서를 유지하며 결과를 정답으로 자동 등록하지 않습니다.

1배속 검사는 영상의 captureStream으로 실제 공유와 같은 수집·병렬 판독 경로를 실행합니다. OS 캡처 시각과 모든 원본 프레임 도착을 재현하지는 않습니다. 사진·재현 파일은 순차 검사만 지원합니다. 재현 파일은 저장된 픽셀과 설정을 사용하며 원래 처리 속도를 재현하지 않습니다.
