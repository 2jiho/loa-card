# 가림 관측과 최신 판독 근거의 경계

`occlusion-debt-boundary.test.ts`는 기존 실사 툴팁 크롭의 테두리 검사와, 합성 이벤트를 사용하는 실제 `FreshnessEvidence` reducer를 결합한 경계 실험이다. 영상 전체 재현이나 실제 자동 종료 재현은 아니다. 동일 group 번호의 새 카드가 알 수 없는 거절 부채를 대체한 후 다른 카드의 확정 근거로 해당 부채를 제거할 수 있음을 보여 준다. 그룹 번호만으로는 같은 카드임을 증명하지 않으므로 이 reducer의 기존 대체 동작을 가림 부채에 그대로 사용하면 안 된다.

안전한 처리의 전제는 가려진 관측과 후속 관측의 동일 카드 연결을 독립적인 검증 가능한 근거로 확정하고, 후속 관측의 원본 출처와 캡처 순서·시각이 가림보다 뒤임을 확인하는 것이다. 그 후 단일 후속 관측에서 이름·각성·장수 근거를 모두 확인해야 한다. 위치 예측, 동일 group·행·열, 스크롤바, 목록 개수, 문자열·시각의 일치나 여러 관측의 필드 합산은 동일성을 증명하지 못한다. 정렬 변경, 추정 불가한 위치, 누락된 입력 또는 출처의 신뢰성 미확인은 연결을 보류한다.

현재 캡처 source는 세션·프레임·슬롯·순서·시각을 기록하지만 이 정보만으로 다른 프레임의 같은 카드임을 보증하지 않는다. `InventoryEvidence`의 확정 순서는 하나의 관측에 각성과 추가 장수가 모두 있고 신뢰 조건을 충족할 때 갱신되지만, 그 카드 ID와 가림 관측 간 연결은 별도 근거가 필요하다. `FreshnessEvidence`의 group 기반 교체는 기존 목적의 정책으로 남겨두며 가림 부채의 인증으로 해석하지 않는다. 이 실험은 스캐너의 동작을 바꾸지 않는다.
